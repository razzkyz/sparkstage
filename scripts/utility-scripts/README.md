# Utility Scripts

Collection of one-off utility scripts and code fragments for various tasks.

## Contents

### User & Role Management
- `get_roles.js` - Get user roles from database

### Analytics & Audit
- `audit_revenue.ts` - Revenue audit and analysis script

### Code Fragments & Scratch
- `scratch.js` - Temporary code snippets (JS)
- `scratch.mjs` - Temporary code snippets (ESM)
- `socks-table-fragment.tsx` - Table component fragment for socks report

## Usage

### Node.js Scripts
```bash
node get_roles.js
```

### TypeScript/Deno Scripts
```bash
deno run --allow-net --allow-env audit_revenue.ts
```

## Purpose

These scripts are:
- **One-off utilities** - Run once or occasionally
- **Code fragments** - Experimental code or snippets
- **Admin tools** - Rare administrative tasks

## Scratch Files

`scratch.js` and `scratch.mjs` are temporary files for:
- Testing code snippets
- Experimenting with APIs
- Quick prototyping

**Feel free to modify or delete** these files as needed.

## Note

Most of these scripts are **not critical** to the application and can be deleted if no longer needed.
