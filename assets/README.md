# Assets

Collection of images, screenshots, and other static assets used for testing and documentation.

## Folder Structure

### 📁 `/test-images/`
Test images used during development:
- `test-image.png` - Sample test image (236KB)
- `test-download.png` - Empty test file for download testing

### 📁 `/screenshots/`
Screenshots for documentation:
- `vercel-login-page.png` - Vercel login page screenshot

## Usage

These files are primarily for:
- **Development testing** - Testing image uploads, downloads
- **Documentation** - Visual references and examples
- **Debugging** - Reproducing image-related issues

## Note

These are **not production assets**. Production images are stored in:
- Cloudflare R2: `sparkstage-public-assets` bucket
- CDN: `cdn.sparkstage55.com`
